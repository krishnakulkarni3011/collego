ARCHITECTURE NOTES
════════════════════════════════════════════════════════════════

Request Flow:
  React Frontend
    → Spring Boot /api/ai/* (JWT auth + context building)
      → FastAPI ai-service (pure AI logic)
        → OpenRouter LLM API (if key set)
        → Smart Stub (if no key, or on LLM error)

Key Design Decisions:
  1. No AI keys required to run — all 9 features work in stub mode
  2. ML prediction/risk use pure math (OLS regression, formula-based)
     so they never need an external model or GPU
  3. AiController injects live DB data into chat context before
     calling the AI service — the LLM receives actual student data
  4. 60s read timeout on RestTemplate prevents LLM latency from
     blocking the main Spring Boot thread pool
  5. All AI endpoint errors return structured error maps — the
     frontend degrades gracefully with user-friendly messages
