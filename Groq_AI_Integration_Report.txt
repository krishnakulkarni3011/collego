SUMMARY
================================================================

The Collego AI features now run on Groq's OpenAI-compatible API:

  Primary model  : openai/gpt-oss-120b
  Fallback model : openai/gpt-oss-20b (same Groq key)
  Base URL       : https://api.groq.com/openai/v1

The model never touches the database. Spring Boot advertises a
role-filtered tool catalogue, executes each requested tool under the
caller's JWT-derived AiScope, and returns only the tool result. Student
identity comes from the token, never from the prompt or tool arguments,
so guessing a USN or injecting instructions cannot reach another
student's records.

The student portal now has two AI entries: AI Assistant and Resume
Analyzer. Performance prediction, attendance risk, placement readiness
and smart search are quick actions inside AI Assistant.

NOT YET DONE
================================================================

1. Embeddings / semantic study-material search.
   Deferred by design: Groq has no embeddings endpoint. Keyword search
   through search_my_study_material remains the fallback. Revisit if a
   separate embedding provider is approved.

2. Automated production frontend build.
   The prod image must be built with an EMPTY VITE_API_URL. This was
   done manually with --build-arg VITE_API_URL= and documented in the
   plan. A CI job or a dedicated prod build script should enforce it so
   a local build can never be promoted again.

3. Groq free-tier data-usage review.
   Before real student data is used at scale, confirm the data-usage
   setting in the Groq console. The free tier may use prompts for
   service improvement.

4. API key rotation.
   The key was shared outside the server during setup. Rotate it in the
   Groq console, update /opt/collego/.env and the local .env, then
   recreate the ai-service. Nothing else needs to change.

5. Git push.
   This round is committed locally. origin/main is behind and the push
   is left to the repository owner, matching the previous rounds.

6. Optional quality tuning.
   AI_MAX_TOOL_ROUNDS can be raised to 2 if the Groq tier is upgraded;
   keep it at 1 while the 8k TPM limit is shared.
